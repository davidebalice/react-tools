# React Tools

A landing page that collects a series of small React projects.
Each card shows a short description of the project with links to its live demo and its GitHub repository.

**Live demo:** <https://react-tools.davidebalice.dev/>

![Screenshot](https://www.aroundweb.it/screenshot/react-tools.jpg)

## Projects included

| Project                | Description                                        | Repository |
| ---------------------- | -------------------------------------------------- | ---------- |

| Loading optimization   | Examples of content loading optimization           | [react-loading-optimization](https://github.com/davidebalice/react-loading-optimization) |
| Events calendar        | Add events to a calendar                           | [react-calendar](https://github.com/davidebalice/react-calendar) |
| Dark mode              | Toggle dark mode with a switch                     | [react-dark-mode](https://github.com/davidebalice/react-dark-mode) |
| Food cart              | Food cart implementation                           | [react-food-cart](https://github.com/davidebalice/react-food-cart) |
| Form validation        | Form validation with Formik and Yup                | [react-form-validation](https://github.com/davidebalice/react-form-validation) |
| Google Maps            | Google Maps integration in React                   | [google-maps-react](https://github.com/davidebalice/google-maps-react) |
| Meteo                  | Weather app based on the Open-Meteo API            | [meteo-app-react](https://github.com/davidebalice/meteo-app-react) |
| Lorem ipsum generator  | Dummy text generator                               | [react-lorem-ipsum-generator](https://github.com/davidebalice/react-lorem-ipsum-generator) |
| Snapshot               | Take a snapshot of a web page with html2canvas     | [react-snapshot](https://github.com/davidebalice/react-snapshot) |

## Getting started

### Requirements

- Node.js 20 or later
- npm

### Installation

```bash
git clone https://github.com/davidebalice/react-tools.git
cd react-tools
npm install
```

### Available scripts

| Command           | Description                              |
| ----------------- | ---------------------------------------- |
| `npm run dev`     | Start the development server             |
| `npm run build`   | Create a production build in `dist/`     |
| `npm run preview` | Preview the production build locally     |

## Project structure

```
src/
├── common/        # Header and footer
├── components/    # Hero slide and project cards
├── assets/        # Images
└── main.jsx       # Application entry point
```
